# DriveLogger Support

DriveLogger catalogs selected folders and drives so you can search their files, even when a drive is disconnected.

- [Privacy policy](PRIVACY.md)
- [Ask for help or report a problem](https://github.com/v66cds2qtr-png/DriveLogger-support/issues)

When reporting a problem, include your macOS version, DriveLogger version, what you expected, and what happened. Issues are public: please do not attach catalogs or disclose private filenames, paths, or personal information.

This repository contains public support information and the privacy policy. The app source is maintained separately.
